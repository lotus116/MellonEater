# Mac 微信导出接入与验收

仅处理用户指定群、日期和主动提供的 ZIP。这里编排本地工具，不会把 skill 当成微信读取接口。

## 当前可运行路径

1. 微信内多选指定消息 → 合并转发 → 其他应用 → 渡口，保存原始 ZIP。避免选择“发给 Codex / Claude”等自动粘贴入口；本流程先本地验收，再由用户启动分析。
2. 首次先用一条文字和一张图片试导出。在微信打开图片并等其加载完成是排查步骤，不是保证能导出原图的修复方案。检查 ZIP 是否确实带图片文件；只有 `[图片] 文件名` 不等于已取得图片。
3. 在仓库根目录执行 `python scripts/inspect-wechat-zip.py <用户指定的ZIP>`。只输出文件、记录、图片引用和对应文件数量，不打印正文或人员信息，也不读取其他目录。`matched_image_files` 只说明文件名匹配；导入时才检查能否解码。
4. 工作台选择“导入微信 ZIP”，填写已授权的群名和日期；多包可一起选。或执行 `python scripts/import-wechat-zip.py <ZIP> --group <群名> --start <含时区时间> --end <含时区时间>`。此步骤不启动模型。
5. 核对首尾记录、分批边界、图片是否实际可见。缺失、同名歧义、格式无法读取分别保留；不能用其他群的同名文件补图，不能依据时间猜配，也不能假定覆盖全部日期。
6. 用当前分析入口生成报告。PDF 和独立 HTML 自动附上阅读稿引用的完整原文及父材料，显示名和时间保持原样；短编号与网页一致。缺图不能写成看过截图。附录是私密核对资料，不是已匿名化公开报告。

## 缺图如何定位

- ZIP 只有 TXT：缺口发生在收到的导出包之前，不能归因于分析模型或导入时删除；需要比较微信新导出的一图样本，才能继续定位。
- 手动合并转发与渡口“快捷微信转发”是两条路径。不要把快捷转发的“保存图片”开关当成所有手动缺图的原因。
- 快捷转发时检查“保存图片”；上游当前默认开启，关闭会过滤图片文件。手动路径优先保留微信提供的原包。
- ZIP 含图片而导入未显示：用原包的文件引用、批次及缺口原因排查解析器，不让用户反复调用模型。
- 若需要重新签名微信或重新登录，先说明原因并等用户配合，不作为默认排查步骤。不得修改微信、关闭系统保护来绕过获取限制。

## 可以整合的范围

已接入：原生 ZIP 格式解析、批次内图文对应、本地缺图验收、导入、现有分析与自包含报告。渡口仍作为独立本地采集工具，未嵌入其应用二进制或分享扩展。

待验证：渡口的辅助功能自动选取（实验功能）在当前微信版本上的可用性、指定主题与日期的完整覆盖、自动导出任务接口。本机此前未取得可用的聊天辅助功能控件；不能声称已稳定自动采集。当前 `dukou://` 路由用于设置页面，不是已确认的聊天导出 API。
